# C Lang Practice

A collection of beginner C programs covering strings, functions, structures, pointers, loops, and basic input/output operations.

## Folder structure

- [`7.Strings/`](7.Strings/) contains string programs and study notes.
  - [Revision notes](7.Strings/strings_notes.md)
  - [Viva questions](7.Strings/strings_viva.md)
- [`8.Functions/`](8.Functions/) contains function programs and study notes.
  - [Revision notes](8.Functions/functions_notes.md)
  - [Viva questions](8.Functions/functions_viva.md)
- [`9.Structures-Pointers/`](9.Structures-Pointers/) contains structures and pointers programs and study notes.

## Compile and run

Use a C compiler such as GCC:

```bash
cd 7.Strings
gcc Program_1_Length.c -o program_1
./program_1
```

On Windows, compiled programs can be run with:

```powershell
cd 7.Strings
.\program_1.exe
```
