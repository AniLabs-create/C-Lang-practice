# C Lang Practice

A collection of beginner C programs covering strings, functions, structures, pointers, loops, and basic input/output operations.

## Folder structure

- [`Lab-7-Strings/`](Lab-7-Strings/) contains string programs and study notes.
  - [Revision notes](Lab-7-Strings/strings_notes.md)
  - [Viva questions](Lab-7-Strings/strings_viva.md)
- [`Lab-8-Functions/`](Lab-8-Functions/) contains function programs and study notes.
- [`Lab-9-Structures-Pointers/`](Lab-9-Structures-Pointers/) contains structures and pointers programs and study notes.

## Programs

| Program | Topic |
|---|---|
| [Program_1_Length.c](Lab-7-Strings/Program_1_Length.c) | Find the length of a string without `strlen()` |
| [Program_2_Vowels.c](Lab-7-Strings/Program_2_Vowels.c) | Count vowels and consonants |
| [Program_3_Reverse.c](Lab-7-Strings/Program_3_Reverse.c) | Reverse a string |
| [Program_4_Palindrome.c](Lab-7-Strings/Program_4_Palindrome.c) | Check whether a string is a palindrome |
| [Program_5_WordCount.c](Lab-7-Strings/Program_5_WordCount.c) | Count words in a string |
| [Program_6_RemoveSpaces.c](Lab-7-Strings/Program_6_RemoveSpaces.c) | Remove spaces from a string |
| [Program_7_StringCopy.c](Lab-7-Strings/Program_7_StringCopy.c) | Copy a string without `strcpy()` |
| [Program_8_StringCompare.c](Lab-7-Strings/Program_8_StringCompare.c) | Compare two strings without `strcmp()` |
| [Program_9_FirstWord.c](Lab-7-Strings/Program_9_FirstWord.c) | Print only the first word of a string |
| [Program_10_CharStats.c](Lab-7-Strings/Program_10_CharStats.c) | Count digits, letters, and spaces |
| [Program_11_SortString.c](Lab-7-Strings/Program_11_SortString.c) | Sort a string alphabetically |

## Compile and run

Use a C compiler such as GCC:

```bash
cd Lab-7-Strings
gcc Program_1_Length.c -o program_1
./program_1
```

On Windows, compiled programs can be run with:

```powershell
cd Lab-7-Strings
.\program_1.exe
```
