# C Lang Practice

A collection of beginner C programs covering strings, arrays, loops, and basic input/output operations.

## Folder structure

- [`Strings/`](Strings/) contains string-related programs and progress notes.

## Programs

| Program | Topic |
|---|---|
| [Program_1.c](Strings/Program_1.c) | Find the length of a string without `strlen()` |
| [Program_2.c](Strings/Program_2.c) | Count vowels and consonants |
| [Program_3.c](Strings/Program_3.c) | Reverse a string |
| [Program_4.c](Strings/Program_4.c) | Check whether a string is a palindrome |
| [Program_5.c](Strings/Program_5.c) | Count words in a string |
| [Program_6.c](Strings/Program_6.c) | Remove spaces from a string |
| [Program_7.c](Strings/Program_7.c) | Copy a string without `strcpy()` |
| [Program_8.c](Strings/Program_8.c) | Compare two strings without `strcmp()` |
| [Program_9.c](Strings/Program_9.c) | Print only the first word of a string |
| [Program_10.c](Strings/Program_10.c) | Count digits, letters, and spaces |
| [Program_11.c](Strings/Program_11.c) | Sort a string alphabetically |

## Compile and run

Use a C compiler such as GCC:

```bash
cd Strings
gcc Program_1.c -o program_1
./program_1
```

On Windows, compiled programs can be run with:

```powershell
cd Strings
.\program_1.exe
```
